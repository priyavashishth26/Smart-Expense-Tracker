# Smart Expense Tracker + Predictor

A Machine Learning based expense tracking web app built using Python and Streamlit.

## Features
- Expense Tracking
- Automatic Category Prediction
- Monthly Spending Analysis
- Future Expense Prediction
- Interactive Dashboard
- Pie Charts and Graphs

## Technologies Used
- Python
- Streamlit
- Pandas
- Scikit-learn
- Matplotlib
- CSS
